The user chose the PRODUCT perspective: questions about what the change means for the people
who use it.

PASS if every question in the JSON quiz is about user and product impact: shoppers seeing or
being charged an outdated price for up to 5 minutes (checkout uses the cache too), which users
or teams are affected (shoppers, pricing or promotions staff), defaults chosen for them (5
minutes, caching at checkout), what was left out of scope, or how to know it works for users
(page speed, mispriced orders, support tickets).

FAIL if any question is mainly about code mechanics (what an expression returns, a line-level
change) or internal architecture with no user consequence, or if there is no JSON quiz.
